# KenFutWiki 公开站首版验收

日期：2026-10-28。上游基线：`0b26db72`；实施分支：`codex/public-site-v1`。本次交付为本地提交，未推送、未部署、未配置远端发布凭证。

## 已实现

- 文档／文章／双入口，共用Node、发布、评论与浏览量；文章署名、封面、展示日期、平铺分类、多标签、精选和推荐。
- 同事务发布正文、文章元数据和manifest；旧slug及NodeID兼容；RAG outbox重试及同Node向量写入串行保护。
- 文章频道、分类标签聚合、关键词搜索、canonical、分享元数据、JSON-LD、sitemap、手机导航及返回顶部。
- CTA、产品页面目录、参数白名单、页面选择器；富文本和Markdown真实选区编辑。
- 评论审核、提示词读写与既有LLM消费链；真实角色权限和公开站能力分开。
- 产品隔离的服务端凭证、事件幂等、30天最后CTA归因、注册锁定、首次成功生成及漏斗查询。
- 独立扩展迁移序列；PV保留原展示基线后逐浏览累计，旧日汇总不会再重复抬高新计数。
- OpenAPI、带TypeScript声明的服务端SDK、通用参考产品、接入及上游合并说明；默认运行遥测及Sentry均需显式自有配置。

## 真实浏览器验收

公开站采用真实PG内容仓库、发布、查询和实际新HTTP处理器，测试站点仅监听本机。

- 桌面文章、双推荐卡片、CTA跳转及参数正确。
- 390×844视口下站名、菜单、图片、CTA和推荐可用；修正`/wiki`下Next bundled资源被重复加前缀的问题。
- 返回顶部平滑滚动最终`window.scrollY=0`。
- 默认关键词入口在没有调用AI的情况下返回3个唯一已发布Node；双入口内容只出现一次。
- 浏览文章→点击CTA→参考用户注册→参考任务成功，经实际HTTP回传入库，结果为`1 → 1 → 1 → 1`，未归因数为0。
- 另用实际SDK重复回传无click_id的参考事件，验证只新增一次未归因里程碑，不伪造文章来源。

编辑器使用实际`@ctzhian/tiptap`、Ace、补丁及生产链接适配器；目录接口为明确标注的固定测试数据。

- 富文本中文选区插入稳定NodeID链接，取消不改正文，一次撤销/重做正确。
- Markdown真实键盘选区`row0,column3..7`读取为“测试文字”，在原位置插入链接。
- 从干净实例开始，一次Cmd+Z恢复完整原文，一次重做恢复链接；修正remove/insert中间状态回灌导致的撤销错误。
- 光标在已有链接内只替换目标，保留相邻正文；取消不改Markdown。

## 验收边界

- 浏览器夹具替代生产ShareAuth/Redis缓存及部分App投影；不代表完整生产认证、S3、NATS或RAG服务已验收。新产品Bearer、权限过滤、内容/事件持久化及回传HTTP链均实际执行。
- 参考生成是可控本地成功结果，没有调用付费模型；未宣称任何真实外部产品完成联调。
- 提示词已验证存储和实际消费读取方法，未验证真实模型回复质量。
- Docker编排和远端CI/CD未运行；后续接入自有registry、secrets、部署及真实业务产品。
- 中文检索是字面匹配；在10000篇样本中验证过短词，当前locale的trigram选择性有局限，不承诺任意规模性能。
- 历史PV保留升级前显示基线，不追溯重算旧版历史误差。事件明细180天，日事件总量及业务里程碑去重事实保留。
- 部署必须将管理端和公开站源码入口配置到实际运行提交或对应源码归档。默认仓库链接不能替代尚未发布的本地分支源码。
- SDK和参考产品沿用AGPL；外部独立产品可以直接实现HTTP/URL协议，不必嵌入SDK。
